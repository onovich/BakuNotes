# 日常使用与本轮验收

## 记录和整理

- 点击「日期、时间与标签」修改梦的日期、采用的记录时间和标签。梦的日期使用有效 `YYYY-MM-DD`；记录时间支持已有中文和数字日期解析。留空表示未知，来源时间保持原值。
- 标签使用英文或中文逗号分隔，保存时去重；点击列表中的标签筛选。可按梦的日期升降序、记录时间或最近编辑排序，未知时间放在末尾。
- 「移入回收站」保留整篇记录；在回收站中打开后可「恢复到梦库」。回收站内容只读，不提供永久清空。JSONL 备份包含回收站，`trashed_at` 保存状态。

## 并发编辑恢复

文件库连接模式遇到 revision 冲突时，点击「保留草稿并载入最新库」。应用先把未保存的快照及原基线写入本机 AsyncStorage，再读取最新文件库；保存恢复快照失败时不会继续载入。

「恢复本地草稿为副本」只恢复本地改动，保留最新库中的原记录。重复恢复同一快照不会再生成同一副本。恢复快照按文件库身份隔离，只保留最近一份，仍应使用独立 JSONL 备份；直接关闭页面前未执行保留操作的失败草稿没有持久恢复保证。

## 文件夹导入

网页版「导入文件夹」递归读取 UTF-8 TXT / MD / MARKDOWN。相对路径作为标题和稳定 ID 的文件名部分，区分不同子目录中的同名文件。空文件、无效编码等错误逐文件列出；有效文件仍可选择导入，其他类型统计为跳过。时间候选只对应成功读取的文件，不错位套用失败文件的时间。支持全选与反选。

不解析 front matter，不加载 Markdown 图片链接。手机仍使用多文件选择，不宣称支持手机文件夹选择。

## 网页原音

「录一段梦」在点击后申请麦克风权限，停止后把收到的原音保存为笔记内嵌附件，并提供本次原音下载和播放器。最长两分钟，每段最多 4 MiB；超限或保存失败时可下载本次原音。录音中断后保留已收到的数据并提示试听检查。离开记录会停止录音；关闭整个页面或浏览器崩溃前的在录音频不保证保存。

无需模型服务，不转写。HTTPS 或 localhost、支持 MediaRecorder 的浏览器才可录音；iOS 原生录音和播放尚未实现。JSONL 包含内嵌原音的 base64 数据；ENEX 的外部附件仍需单独备份转换目录。大量原音会增大整库快照，本地 HTTP 快照限制为 16 MiB。
