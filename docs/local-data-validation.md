# 本地数据验收

## 已完成

- 网页连接模式通过真实 HTTP 服务及网页使用的 storage adapter 验证，与 CLI 和实际 stdio MCP 子进程共用同一文件库。网页写入能被 MCP 读到，MCP 导入能被重新载入；版本冲突不覆盖文件库，相同快照响应丢失重试不增加 revision。无凭证、异源、错误 Host、非法快照和静态目录联接越界均被拒绝。该验证未操作页面输入控件，连接模式的浏览器交互尚待验收。

- 本地 stdio MCP 通过官方 SDK Client 实际执行协议握手、工具发现与调用；虚构笔记导入、幂等重试、搜索、导出校验、第二个文件库恢复及 CLI 互读均通过。只读模式仅提供四个读取工具，越界路径、符号链接/junction 和伪造计划来源被拒绝。该验收不涉及网页同库连接。

- 文件库 CLI 已代办 8 篇真实候选的导入、跨进程磁盘读回、备份导出/校验、独立空白文件库恢复及逐字段比较；全部通过，再导入时 8 篇均识别为重复。未采用时间，正文和来源原件未改变；该结果不代表浏览器存储验收。样本、文件库和结果均在 Git 忽略目录。

- 少量虚构记录：网页创建、确认保存、刷新读回、实际导出备份，并在独立空白本地站点恢复；重复 ID 在导入预览中标出。
- 1,500 篇生成记录：每篇含 20 行中文正文、日期、标签、来源和附件元数据，JSONL 共 3,226,146 字节。自动测试验证保存队列写入的 JSON 快照、重新读取、JSONL 导出与解析后内容完全一致，全部 ID 可识别为已有记录。
- 2026-10-01，用户在 Codex 侧边浏览器手动验收 1,500 篇记录：在 `http://127.0.0.1:8771/` 导入并搜索 `01500`，编辑正文加入“保存验收通过”，等待保存后刷新，确认新增文字仍在；导出当前备份，在独立空白站点 `http://127.0.0.1:8772/` 恢复，确认篇数为 1,500，并再次找到新增文字。
- 梦库列表使用 FlatList 按需渲染，避免直接创建全部记录行；导入预览也使用 FlatList。API 约定见 [React Native 文档](https://reactnative.dev/docs/flatlist)。
- 2026-10-01，侧边浏览器自动化重新可用。以三份虚构 TXT / MD 文件验证：全选后反选归零；首行时间批量应用成功；缺失和歧义的两篇阻止确认；无时间笔记不显示首末行及创建时间候选；手动输入中文日期后只写入记录时间；歧义日期列出日/月和月/日两项。逐篇确认后成功导入，刷新后梦的日期、记录时间和导入时间均保留，正文未改变。

批量自动测试使用内存中的存储替身，验证数据契约与队列行为；实际网页保存与恢复由上述手动验收补充。没有测量交互耗时、存储容量上限或移动设备性能，也没有给执行时间设置硬性阈值。
